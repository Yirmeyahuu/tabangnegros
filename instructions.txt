HOW TO BUILD A NEW VERSION (ANDROID)
================================================================================

STEP 1: UPDATE VERSION NUMBERS
--------------------------------------------------------------------------------
Location: frontend/android/app/build.gradle

Find and update these lines:

    android {
        defaultConfig {
            versionCode 2          // INTEGER - Increment by 1 (1, 2, 3, 4...)
            versionName "1.1.0"    // STRING - Semantic version (1.0.0, 1.1.0, 2.0.0)
        }
    }

Version Naming Convention:
  - Major: Breaking changes (1.0.0 → 2.0.0)
  - Minor: New features (1.0.0 → 1.1.0)
  - Patch: Bug fixes (1.0.0 → 1.0.1)

IMPORTANT: 
  - versionCode MUST be higher than previous version (for Play Store updates)
  - versionName is what users see

================================================================================
BUILDING RELEASE APK (FOR PRODUCTION/PLAY STORE)
================================================================================

STEP 1: Generate Keystore (First time only)
--------------------------------------------------------------------------------
keytool -genkey -v -keystore tabangnegros-release.keystore \
  -alias tabangnegros -keyalg RSA -keysize 2048 -validity 10000

Save the keystore file and passwords securely!


STEP 2: Create keystore.properties
--------------------------------------------------------------------------------
File: frontend/android/keystore.properties

storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=tabangnegros
storeFile=/path/to/tabangnegros-release.keystore


STEP 3: Update build.gradle
--------------------------------------------------------------------------------
File: frontend/android/app/build.gradle

Add before 'android' block:

def keystorePropertiesFile = rootProject.file("keystore.properties")
def keystoreProperties = new Properties()
keystoreProperties.load(new FileInputStream(keystorePropertiesFile))

Inside 'android' block, add:

signingConfigs {
    release {
        keyAlias keystoreProperties['keyAlias']
        keyPassword keystoreProperties['keyPassword']
        storeFile file(keystoreProperties['storeFile'])
        storePassword keystoreProperties['storePassword']
    }
}

buildTypes {
    release {
        signingConfig signingConfigs.release
        minifyEnabled true
        proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
    }
}


STEP 4: Build Release APK
--------------------------------------------------------------------------------
cd /Users/jeremiahpantaras/Documents/tabangnegros/frontend/android
./gradlew assembleRelease

Output: app/build/outputs/apk/release/app-release.apk


STEP 5: Build App Bundle (For Play Store)
--------------------------------------------------------------------------------
cd /Users/jeremiahpantaras/Documents/tabangnegros/frontend/android
./gradlew bundleRelease

Output: app/build/outputs/bundle/release/app-release.aab

Upload .aab file to Google Play Console

COMMON ISSUES & SOLUTIONS
================================================================================

Issue: Build fails with Java version error
Solution:
  export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
  export PATH=$JAVA_HOME/bin:$PATH
  ./gradlew --stop
  ./gradlew assembleDebug

Issue: "SDK location not found"
Solution:
  Create frontend/android/local.properties:
  sdk.dir=/Users/jeremiahpantaras/Library/Android/sdk

Issue: ADB device not found
Solution:
  # Enable USB Debugging on phone
  adb kill-server
  adb start-server
  adb devices

Issue: App crashes on startup
Solution:
  # Check Android Studio Logcat for errors
  adb logcat | grep TabangNegros

Issue: API not responding (503 error)
Solution:
  # Render free tier spins down after 15 mins
  # First request takes 30-60 seconds to wake up
  # Wait and retry

Issue: Location not working
Solution:
  # Check app permissions: Settings → Apps → Tabang Negros → Permissions
  # Enable Location permission
